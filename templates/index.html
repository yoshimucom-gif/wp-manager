// v1.7.19 (2026-06-09) — 本番一括投入前の事故防止 3 点（過去日付ガード／画像保持／復旧誤操作の警告）
  • ① 過去日付の schedule_date が即時公開される罠を塞いだ（本体）:
    • /api/schedule-publish は status=future を送るだけで日付チェックしていなかった。WP は過去日付 + future を渡すと即時公開する仕様のため、CSV の打ち間違い1件が意図せぬ即時公開につながる危険があった。
    • 修正: バックエンドで「5分以上過去の予約日」を明示エラーで停止。モーダルプレビューにも「⛔ 予約日が過去」セクションを追加してリスト表示。
  • ② リライト時の画像消失を防止（rewrite v0.4.38）:
    • プロンプトの「使ってよいタグリスト」に <img> が含まれていなかったため Claude が画像を落とすケースがあった。
    • 修正: <figure>/裸 <img> を <!--AFFIROS_MEDIA_N--> プレースホルダーに置換して Claude へ送り、応答後に元のメディアに戻すプレースホルダー方式に変更。Claude が落としたものは記事末尾に救済挿入。プロンプトにも明示ルールを追加して二重防御。
  • ③ 「復旧を試みる」誤操作を防ぐ警告バナーを追加（rewrite v0.4.38）:
    • WP 管理画面の Affiros リライター系ページに、直近100件をサンプルチェックして「壊れた wp:table が N 件あります。『復旧を試みる』は絶対に押さないでください」という赤枠バナーを表示。修復ページへのリンク付き。
    • スキャン結果は 1 時間キャッシュ。修復が走るとキャッシュ即クリア。
// v1.7.18 (2026-06-09) — リライター: 壊れた既存記事のテーブルブロックを一括修復するページを追加（rewrite v0.4.37）
  • 背景: v1.7.17 (rewrite v0.4.36) で「これから生成する記事」は壊れなくなったが、それ以前にリライト済みの大量の記事は壊れたまま残っていた。1件ずつ手動で修復するのは現実的でない。

    • 壊れた wp:table ブロックを含む記事のみをリスト表示。

// v1.7.17 (2026-06-09) — リライターの比較テーブル消失バグを修正（rewrite v0.4.36）
  • 症状: リライト後の記事を WP 編集画面で開くと、比較テーブルが「このブロックには、想定されていないか無効なコンテンツが含まれています」と赤エラー表示。「復旧を試みる」を押すとブロックごと消失し、H2 と H2 の間が空になって連続H2状態になる。
  • 原因: wp:table ブロックは HTML スキーマが厳格（<figure class="wp-block-table"> ラップ + <tbody> 必須 + 属性制限あり）だが、Claude が返す <table border="1" style="..."><tr>…</tr></table> のような HTML をそのまま `<figure>` でラップしていたため、validation 失敗 → 「復旧を試みる」でコンテンツごと消えていた。
  • 修正（rewrite v0.4.36）:
    • Gutenberg::normalize_table_for_gutenberg() を新規追加。<table> 出力を Gutenberg 互換に正規化。
    • <table>/<tr>/<thead>/<tbody> の不要属性を全剥がし、<td>/<th> は colspan/rowspan/scope のみ保持。
    • <thead>/<tbody> の外にある裸 <tr> を自動で <tbody> ラップ。
  • 注意: 既に作成済みの壊れたテーブルブロックは、再リライトすると正常に置き換わる。
// v1.7.16 (2026-06-09) — リライターの「元記事が長すぎます」誤判定を修正（rewrite v0.4.35）
  • 症状: 本文 8000 字程度の記事でも「元記事が長すぎます（50432文字 / 上限30000文字）」で一括リライトが全件失敗するケースがあった。
  • 原因: 長さ判定が「生HTMLのバイト数」を見ていた。<!-- wp:paragraph --> などの Gutenberg ブロックコメント・大量の inline style 付き <div>/<span> などのマークアップが本文の 5〜6 倍に膨らんで上限を超えていた。
  • 修正（rewrite プラグイン v0.4.35）:
    • Pre_Cleanup に Gutenberg ブロックコメントの除去を追加。Claude に渡す入力からも無駄なノイズが消える（プロンプト効率改善）。
    • Rewrite_Engine の MAX_SOURCE_CHARS 判定を「タグ・コメント除去後の本文文字数」で行うように変更。エラーメッセージも「本文 X文字」と明示。
  • 効果: 装飾だらけの記事もリライト可能に。本来弾くべき「本文 3万字超」の長文記事はこれまで通り中断される。
  • 更新方法: プラグインページから affiros-rewrite-0.4.35.zip を再インストール。
