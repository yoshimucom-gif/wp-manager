API設定
Claude API・デフォルト設定
// Claude API 設定
// 商品カード挿入ルール
記事生成時に <!--ai-product:...--> マーカーを記事本文へ埋め込みます。WordPress側の AI Product Inserter プラグイン が該当箇所を商品カードに置換します。
既定の挿入ルール:
  • ランキング記事: 各 h3 直下に縦置き + まとめ後にランキングTOP3
  • 商標記事: 最初のH2直後・まとめ前 に縦置き
  • コラム記事: 最初のH2直前に縦置き×2 + まとめ後にランキングTOP3
// Amazon PA-API v5（推奨・優先）
Amazonアソシエイト商品検索用。設定するとAmazonが優先で使われます（CV率重視）。楽天はフォールバックとして使用。
// 楽天市場API（フォールバック）
楽天ウェブサービスの商品検索用。Amazonが未設定 or 検索失敗時のフォールバックとして使用。アフィリエイトIDを併設すると参照リンクが自動でアフィリエイト化されます。
// 記事CSS定義（全サイト共通）
HTMLやGutenbergブロックはここに入れず、CSSだけを入力してください。
// デフォルト設定
// 品質定義を追加
内容ではなく、文章構成・権威性・根拠の置き方・説得力の出し方だけを参考にします
完成記事のHTMLを貼ると、見出し順・表・CTA配置・HTMLブロック構成だけを参考にします
// サイトを追加
WordPressのユーザー設定で発行したアプリケーションパスワードを入力してください。
// 本文/設定編集
ここで保存してもWordPressには反映されません。既存投稿へ反映する場合は、保存後に生成画面で内容を確認してから「WPへ上書き送信」を実行してください。
// ランキング記事から商標記事へ展開
ランキング記事の表や「1位：商品名」見出しから候補を抽出します。ここでは商標記事の未生成下書きだけ作成し、本文生成は実行しません。
作成される下書き: 商標記事 / 親ランキング記事・投稿先サイト・カテゴリーを引き継ぎます。
例: 商品名の口コミ・評判レビュー｜メリット・デメリットを解説
