品目ごとの商品データを同梱し、ショートコードで掛け合わせ絞り込みページを出します。

== 使い方 ==

固定ページの本文にショートコードを置きます。

  [interior_finder set="chest"]

属性

  set    データのファイル名（data/<set>.json）。必須
  title  絞り込みの上に出す小見出し。省略するとテーマの見出しに任せて何も出しません
  cols   商品一覧の列数。2〜4（既定 3）。画面が狭いときは2列になります

== 絞り込みの中身 ==

* 置きたい場所の実寸（幅・奥行・高さの上限）を入れると、そこに収まる商品だけが残ります
* 幅・奥行・高さの区分、段数・素材・色・置き場所・入れるもの、キャスター／扉の有無
* 同じ軸の中はOR、軸をまたぐとAND
* 各選択肢には「いま押したら何点になるか」が出て、0点になる選択肢は押せません
* 選んだ条件はバーに並び、ひとつずつ外せます
* 絞った状態はURLに残るので、そのURLを人に送れます（こちらからリンクは張りません）

== 品目を増やすとき ==

data/<slug>.json を足すだけです。絞り込みの軸と寸法の区分はJSONの中に入っています。
JSONは記事側のリポジトリにある tools/export_finder_set.py が作ります。

  py tools/export_finder_set.py <slug> <表示名> work/db/<slug>_db.json

== 作りの決まり ==

* 商品は全点サーバー側で描き、絞り込みは表示の出し入れだけ。検索エンジンには全商品が見える
* 価格・口コミ・星の数は扱わない（Amazonアソシエイト規約）
* 色はテーマの配色とぶつからないよう無彩色。Amazonのボタンだけ公式の橙
* 自動更新はGitHub直配信（plugin-host/api/plugin-update/interior-finder）
