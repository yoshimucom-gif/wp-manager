# 装飾・整形プラグイン

Claude APIによる **AI自動装飾**（マーカー・赤字・強調ボックス・アイコンリスト等）と、
機械的な **段落整形**（長段落分割・句読点正規化・見出し昇格）を統合したWordPressプラグイン。

DBP テーマ用の Gutenberg ブロック生成を前提としています。

## 主な機能

### 🎨 AI装飾
- Claude APIで記事内容を解析し、適切な箇所にDBPテーマの装飾ブロックを挿入
- 装飾レベル 3段階：軽め / 標準 / 盛り盛り
- モデル選択：Haiku 4.5 / Sonnet 4.6 / Opus 4.7 / Opus 4.6
- ロールバック機能：装飾前の本文を自動バックアップ、ワンクリックで復元
- バリデーション：ブロック構文チェック、文字数比較、見出し保持確認
- 検証エラー時は再生成プロンプトにエラー内容をフィードバックして自動リトライ（最大2回）
- 絞り込み一括処理：カテゴリ・タグ・装飾状況で対象を絞って実行
- 処理ログ：全実行履歴と使用トークン数を記録
- 個別除外：装飾したくない記事は対象外フラグで保護

### 📝 段落整形
- 長すぎる段落を句点・接続詞・最大文字数で機械的に分割
- 「ポイントN：」「ステップN：」等の見出しっぽい段落を自動でh4に昇格
- リスト内の「`<strong>ラベル</strong>：長文`」を「見出し + 段落」に分解
- H2/H3・画像・表の前後に空段落を挿入して視覚的余白を確保
- 句読点の連続（「。。」→「。」）を正規化
- 全記事スキャン → before/afterプレビュー → 個別 or 一括適用
- 保存時に自動整形するオプション（デフォルトOFF）

## インストール

1. `decoration-formatter` フォルダごと `/wp-content/plugins/` にアップロード
   （または zip を WP管理画面「プラグイン」→「新規追加」→「プラグインのアップロード」）
2. WordPress管理画面の「プラグイン」で「装飾・整形プラグイン」を有効化
3. 左メニュー「装飾・整形」→「設定」でClaude APIキーを入力

## 使い方

### AI装飾

**個別記事（推奨：最初はこちらでテスト）**
1. 投稿を編集画面で開く
2. サイドバー「🎨 AI装飾」ボックスを確認
3. 「プレビューモード」にチェックを入れて「装飾を実行」
4. 結果を確認し、問題なければチェックを外して再実行で本保存
5. 元に戻したい場合は「装飾を元に戻す」

**一括処理**
1. 左メニュー「装飾・整形」→「🎨 AI装飾（一括）」
2. カテゴリ・タグで対象記事を絞り込み
3. 「対象記事を確認」で件数・推定コストを表示
4. 「一括処理を開始」で実行

### 段落整形

**個別記事**
1. 投稿を編集画面で開く
2. サイドバー「📝 段落整形」ボックスで統計を確認
3. 「この記事を整形」で即整形（リビジョンが自動保存されるので元に戻せます）

**一括処理**
1. 左メニュー「装飾・整形」→「📝 段落整形（一括）」
2. 「全記事スキャン」で整形対象をリストアップ
3. 各行の「プレビュー」で before/after を確認
4. 「適用」or「全件に適用」で実行

## 使用するDBPテーマブロック

| ブロック | 用途 |
|---|---|
| `dbp/frame` (good型) | ポイント・コツ・おすすめ等の強調ボックス |
| `dbp/frame` (default) | 注意点・補足等の通常ボックス |
| `dbp-e-marker` | 黄色マーカー |
| `dbp-e-color` | 赤字強調 |
| `dbp-e-badge` | バッジ |
| `dbp-list` | アイコン付きリスト |

## 注意事項

- 一括処理（AI装飾）は**最初は5〜10件で必ずテスト**してから
- 装飾品質に不満があれば装飾レベルを変更、それでも合わなければ `prompts/system-*.txt` を直接編集
- AI装飾のバックアップは投稿の post_meta `_decofmt_backup` に保存
- 段落整形は WordPressのリビジョン機能で元に戻せます

## トラブルシューティング

**APIエラーが出る**
- 設定でAPIキーが正しく入力されているか確認
- Claude API 残高があるか確認

**装飾結果が「⚠️ 要確認」になる**
- 文字数の極端な変化（70%未満や200%超）で警告
- 編集画面で内容確認、必要なら手動修正 or ロールバック

**装飾結果が崩れている**
- プロンプトを `prompts/` で調整
- モデルを Opus に変更（高精度・高コスト）
