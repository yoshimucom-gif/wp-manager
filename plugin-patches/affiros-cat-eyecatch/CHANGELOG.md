# Affiros カテゴリーアイキャッチ 改修履歴

## v1.0.0 (2026-07-29) — 新規

- カテゴリー編集画面に「カテゴリーアイキャッチ」フィールドを追加（メディアライブラリから選択）
- カテゴリー一覧に「アイキャッチ」列を追加（親から継承している場合は薄く表示）
- フロントの仮想適用: アイキャッチ未設定の記事に、カテゴリーの画像を自動で使う
  （`get_post_metadata` フィルタ1本。テーマ改修不要、DBには書き込まない）
- 適用の優先順位: 実アイキャッチ > 主要カテゴリー(Yoast/Rank Math) > 他カテゴリー > 親から継承 > 全体デフォルト
- 管理画面・REST・WP-CLI では仮想適用を無効化（ブロックエディタでの焼き付き事故を防ぐ）
- 設定画面（設定 → カテゴリーアイキャッチ）: 有効/無効・対象投稿タイプ・対象タクソノミー・親継承・デフォルト画像
- 一括適用ツール: スキャン（カバー状況と画像未設定カテゴリーの一覧）→ 実アイキャッチとして書き込み → 一括取り消し
  - 対象はアイキャッチ未設定の記事のみ。既存のアイキャッチは上書きしない
  - 書き込んだ画像IDを目印として保存し、取り消し時は現在値と一致する記事だけ戻す
- ke-ys.co.jp 配信ホストからの自動更新に対応（`/api/plugin-update/cat-eyecatch`）
