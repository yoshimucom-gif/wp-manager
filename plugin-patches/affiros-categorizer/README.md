# Affiros カテゴライザー プラグイン

記事の本文を Claude API で解析し、**そのサイトの既存カテゴリー**へ自動で振り分ける
WordPress プラグイン。wp_manager (Affiros9) の companion プラグインのひとつ。

## 設計目的

wp_manager から投稿した記事は、カテゴリー未設定（「未分類」）のまま公開されがち。
このプラグインは公開時に本文を解析し、適切なカテゴリーを自動で紐付けることで
「未分類」の量産を防ぐ。

## 他サイトでも動く設計

分類表をコードに持たず、`get_terms()` で**サイトの実際のカテゴリーを動的に読み取る**。
親子階層も WordPress のカテゴリーツリーから自動で組み立てるため、ジャンルの異なる
どのサイトに入れてもそのまま動作する（サイトごとの改修不要）。

判定のヒントは各カテゴリーの **「説明」欄** から取る。説明を埋めるほど精度が上がる。

## 機能

- **公開時の自動分類** … 記事が公開されると WP-Cron 経由で非同期に分類（公開リクエストをブロックしない）
- **一括分類画面** … 公開済み記事を一覧から選択してまとめて分類。「未分類のみ」で絞り込み可能
- **投稿編集画面のメタボックス** … 1記事をその場で再判定
- **上書きモード** … 自動分類時に「未分類の記事だけ」/「常に上書き」を選択
- **サイト説明** … サイトのジャンル・読者層をプロンプトに添えて精度を上げる

## インストール

WP 管理画面 → プラグイン → 新規追加 → アップロード → ZIP を選択 → インストール → 有効化

## 設定

### 方法A: 管理画面で設定

1. WP 管理画面 → Affiros カテゴライザー → 設定
2. Claude API キーを入力（Anthropic Console で発行）
3. 「設定を保存」

### 方法B: wp-config.php で設定（推奨・キーが消えない）

`wp-config.php` に次の行を追加:

    define('AFFIROS_CATEGORIZER_API_KEY', 'sk-ant-xxxxx');

この方式ならプラグインの更新・再インストール・削除でもキーが残る。
定数が定義されている場合は管理画面のキー入力欄より定数が優先される。

### 精度を上げるコツ

- 各カテゴリーの「説明」欄（投稿 → カテゴリー）を埋める。設定画面に未記入の
  カテゴリーが赤字で表示される。
- 設定画面の「サイトの説明」にサイトのジャンル・読者層を書く。

## 使い方

- **自動**: 設定で「公開時の自動分類」をオンにしておけば、公開時に自動で分類される。
- **一括**: Affiros カテゴライザー → 一括分類 → フィルタで絞り込み → 「投稿を取得」→
  チェック → 「選択した記事を分類」。
- **単記事**: 投稿編集画面の「Affiros カテゴライザー」メタボックスのボタン。
