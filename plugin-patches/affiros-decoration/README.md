# AIデコレーション

Claude APIを使ってAI生成記事をDBPテーマのGutenbergブロックで自動装飾するWordPressプラグイン。

## 主な機能

- ✨ **AI自動装飾**: Claude APIが記事内容を解析し、適切な箇所にDBPテーマの装飾ブロックを挿入
- 🎚 **3段階の装飾レベル**: 軽め / 標準 / 盛り盛り から選択可能
- 🔄 **ロールバック機能**: 装飾前の本文を自動バックアップ、ワンクリックで復元
- ✅ **バリデーション**: Gutenbergブロック構文チェック、文字数比較、見出し保持確認
- 📋 **絞り込み一括処理**: カテゴリ・タグ・装飾状況で対象を絞って実行
- 📊 **処理ログ**: 全実行履歴と使用トークン数を記録
- 🚫 **個別除外**: 装飾したくない記事は対象外フラグで保護

## インストール

1. `ai-decoration` フォルダごと `/wp-content/plugins/` にアップロード
2. WordPress管理画面の「プラグイン」から「AIデコレーション」を有効化
3. メニュー「AIデコレーション」→「設定」からClaude APIキーを設定

## 使い方

### 1. 個別記事の装飾（推奨：最初はこちらでテスト）

1. 任意の投稿を編集画面で開く
2. サイドバーの「🎨 AIデコレーション」ボックスを確認
3. 「プレビューモード」にチェックを入れて「装飾を実行」をクリック
4. 装飾結果を確認し、問題なければチェックを外して再実行で本保存
5. 元に戻したい場合は「装飾を元に戻す」ボタン

### 2. 一括処理

1. メニュー「AIデコレーション」→「一括処理」
2. カテゴリ・タグで対象記事を絞り込み
3. 「対象記事を確認」で件数・推定コストを表示
4. 「一括処理を開始」で実行
5. 進捗バーで処理状況を確認、必要なら中断可能

## 装飾ブロック

本プラグインが使用するDBPテーマブロック：

| ブロック | 用途 |
|---|---|
| `dbp/frame` (good型) | ポイント・コツ・おすすめ等の強調ボックス |
| `dbp/frame` (default) | 注意点・補足等の通常ボックス |
| `dbp-e-marker` | 黄色マーカー |
| `dbp-e-color` | 赤字強調 |
| `dbp-e-badge` | バッジ |
| `dbp-list` | アイコン付きリスト |

## 重要な注意事項

- 一括処理は**最初は5〜10件の少量で必ずテスト**してください
- 装飾品質に問題があれば設定の「装飾レベル」を調整
- それでも合わない場合は `/prompts/system-*.txt` を直接編集
- バックアップは投稿のpost_meta `_ai_deco_backup` に保存されます
- 完全削除する場合は手動でメタ情報も削除してください

## トラブルシューティング

### APIエラーが出る
- 設定画面でAPIキーが正しく入力されているか確認
- Claude API残高があるか確認

### 装飾結果が「⚠️ 要確認」になる
- 文字数の極端な変化（70%未満や200%超）で警告
- 編集画面で内容を確認し、必要なら手動修正 or ロールバック

### 装飾結果が崩れている
- プロンプトを `prompts/` ディレクトリ内で調整
- モデルを Opus に変更（高精度・高コスト）
