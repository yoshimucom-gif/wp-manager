## [1.2.1] - 2026-05-22

### 修正（バグ）
- `enable_faq` 設定の未定義キーアクセスを null セーフ化。PHP 8 系で発生していた
  `Undefined array key` 警告を解消。— `includes/decorator.php`
- 投稿編集画面メタボックスの処理結果表示で、装飾結果のエラー／警告メッセージを
  `escapeHtml` でエスケープ。モデル出力に含まれる HTML 断片による XSS を防止。
  — `assets/admin.js`
- バリデーションのブロック対応チェックで、自己終了ブロック `<!-- wp:xxx /-->` を
  開始ブロック数に数えないよう正規表現を修正。開始/終了不一致の誤検出を解消。
  — `includes/validator.php`

### 改善
- 装飾失敗時の再試行で、検証エラーの内容を再生成プロンプトにフィードバック
  するよう変更。従来は同じプロンプトで投げ直すだけだったが、ブロック開閉や
  属性 JSON 構文の具体的な不備をモデルに伝えて修正させる。特に Haiku での
  JSON ミス系の失敗が回復しやすくなる。— `includes/claude-api.php` / `includes/decorator.php`
- 処理ログ画面に「ログをすべて削除」ボタンを追加（nonce 検証付き）。
  投稿の装飾状態・バックアップには影響しない。— `admin/logs.php`
- 設定画面で API キーを全文 HTML 出力しないようマスク表示に変更。
  空欄のまま保存すると既存キーを維持する。— `admin/settings.php`

## [1.2.0]

### 変更
- 配布物のディレクトリ構造を `affiros-decoration/` サブディレクトリに統一。
- 旧プラグイン（`ai-decoration`）との二重ロード防止ガードを追加。
  `AI_DECO_VERSION` が既に定義済みの場合は、管理画面に注意を表示して
  本プラグインの読み込みを中止する（クラス二重定義による PHP Fatal を回避）。
