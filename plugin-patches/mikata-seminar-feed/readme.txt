=== ミカタセミナー 更新情報 ===
Version: 1.0.0

ミカタセミナー（https://mikata-seminar.jp/）に掲載中のセミナーを1日1回取得して保存し、
ショートコードで表示します。

■ なぜプラグインが要るのか
掲載元にRSSもサイトマップもAPIも無く、セミナー名はページのHTMLの中にしかありません。
ページに置いたJavaScriptから他サイトを直接読むのはブラウザ側の制限で止められるため、
WordPress側（サーバー側）で取りに行って保存する必要があります。

■ 入れ方
1. 「プラグイン」→「新規追加」→「プラグインのアップロード」でこのZIPを選ぶ
2. 「今すぐインストール」→「有効化」
3. 有効化した時点で1回取得します（以降は1日1回、自動）

■ 使い方
固定ページや投稿にショートコードを置きます。

    [mikata_seminar limit="3"]

指定できるもの
  limit … 表示する件数（既定 3）
  date  … 開催日時を出すか（no で非表示）
  cat   … 区分（売買仲介など）を出すか（no で非表示）
  state … 受付状況（受付中！など）を出すか（no で非表示）

■ 管理画面
「設定」→「ミカタセミナー」
  ・保存している件数、最後に取得できた時刻、次回の自動取得
  ・「いま取得する」ボタン
  ・いま保存している内容の一覧
  ・エラーが出ていればその内容

■ 取れなくなったときの動き
掲載元の作りが変わって読み取れなくなっても、前回取得できた内容をそのまま表示し続けます。
公開ページが空になることはありません。管理画面の「最後のエラー」に理由が出ます。
復旧は、プラグイン本体の parse() の正規表現を直すだけで済みます。

■ 取得している項目
タイトル／リンク／開催日時／区分／サムネイル画像／受付状況
（動画セミナーには開催日時がないため、その場合は日時が空になります）

■ 取得先に負担をかけない作り
・1日1回だけ。ページ表示のたびには取りに行きません
・取得は20秒でタイムアウト
・保存するのは最大12件
