# 01 Overview

## プロジェクト名

Affiros9

## 目的

WordPress向けのアフィリエイト記事自動化システム。

やりたいこと:

- ランキング記事生成
- 商標記事生成
- コラム記事生成
- SEOリライト
- CSV / Excel 一括インポート
- Amazon / 楽天 API 連携
- Rinker風の商品リンク挿入
- WordPress下書き投稿
- 既存WordPress投稿の上書き
- 記事スコア管理
- 低品質記事のリライト対象化
- 1日20記事までの投稿スケジュール
- 24時間で100記事程度の量産体制

## UI方針

Kairos3 Marketing 風の管理画面。

- 黒いグローバルナビ
- 青アクセント
- Affiros9 ロゴ
- 日本語に馴染む丸めのフォント
- 実用画面をトップに置く

## メニュー構成

- 記事作成
  - ランキング記事
  - 商標記事
  - コラム記事
- 一括処理

- 定義設定
